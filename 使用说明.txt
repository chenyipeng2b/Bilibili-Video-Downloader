========================================
  B站视频下载器 - 使用说明
========================================

【前提】
  - Windows 或 macOS 系统
  - Chrome / Edge 浏览器
  - Python 3.10+ (https://www.python.org/downloads/)
    Windows 安装时务必勾选 "Add Python to PATH"


【三步安装】

 第1步: 启动本地下载服务
         - Windows: 双击 "启动服务.bat"
         - macOS:  双击 "启动服务.command"
           如果系统拦截，请右键文件并选择一次“打开”
         - 首次会创建 .venv，并自动下载依赖和 FFmpeg
         - 看到 http://127.0.0.1:8765 即成功
         - 窗口不要关！

 第2步: 加载浏览器扩展
         Chrome: 地址栏输入 chrome://extensions/
         Edge:   地址栏输入 edge://extensions/
         -> 打开右上角"开发者模式"
         -> 点击"加载已解压的扩展程序"
         -> 选择本文件夹里的 "extension" 文件夹
         -> 扩展图标出现在右上角

 第3步: 打开任意 B站视频页面，点右上角扩展图标即可下载


【功能说明】

  下载模式
    [视频+音频]  正常下载 MP4/MKV
    [仅音频]     MP3 / FLAC / Hi-Res 三选一

  弹幕
    [软封装 MKV]  弹幕作为字幕轨道，需 PotPlayer/VLC
    [硬烧录]      弹幕直接刻入画面，任何播放器都能看
                  (下载较慢，文件较大)

  画质
    全部 12 种画质展示，登录后可解锁更高画质

  日志复制
    点击扩展弹窗顶部的 [LOG] 按钮
    会将扩展端和后端最新 500 条日志以 JSON 格式复制到剪贴板
    日志按时间从新到旧排列
    服务未启动时会自动复制扩展本地保存的诊断日志


【常见问题】

  Q: 扩展显示"下载服务未启动"
  A: Windows 运行 "启动服务.bat"，macOS 运行 "启动服务.command"
     保持服务窗口开启，看到 8765 端口即成功

  Q: 高画质(4K/1080P60)显示锁图标
  A: 需要登录 B站，扩展会自动读取你的登录态

  Q: 下载的 MKV 没弹幕
  A: 右键 -> 字幕 -> 启用字幕轨道，或用硬烧录模式

  Q: LOG 按钮显示“复制失败”
  A: 现在只有剪贴板写入失败才会显示该状态
     服务离线诊断会自动复制；启动详情见 backend/logs/startup.log


【分享给朋友】

  分享时不要包含自动生成的 .venv 文件夹。对方解压后：
  1. 运行对应系统的启动文件（会自动安装依赖和 FFmpeg）
  2. 浏览器加载 extension 文件夹
  3. 打开 B站视频页就能用

========================================
  Bilibili Video Downloader - User Guide
========================================

【Prerequisites】
  - Windows or macOS
  - Chrome / Edge browser
  - Python 3.10+ (https://www.python.org/downloads/)
    Windows: check "Add Python to PATH" during installation


【3-Step Setup】

 Step 1: Start the local service
         - Windows: double-click "启动服务.bat"
         - macOS:  double-click "启动服务.command"
           If macOS blocks it, right-click the file and choose Open once
         - First run creates .venv and downloads dependencies + FFmpeg
         - Keep the window open (service on port 8765)

 Step 2: Load the browser extension
         Chrome: go to chrome://extensions/
         Edge:   go to edge://extensions/
         -> Enable "Developer mode" (top right)
         -> Click "Load unpacked"
         -> Select the "extension" folder in this directory
         -> Extension icon appears in toolbar

 Step 3: Open any Bilibili video page, click the extension icon to download


【Features】

  Download Mode
    [Video+Audio]  Download as MP4/MKV
    [Audio Only]   MP3 / FLAC / Hi-Res (three options)

  Danmaku (Bullet Comments)
    [Soft Mux MKV]  Danmaku as subtitle track (needs PotPlayer/VLC)
    [Hard Burn]     Danmaku burned into video frames (any player)
                    (slower download, larger file size)

  Quality
    All 12 quality tiers displayed, login to unlock higher qualities

  Log Copy
    Click the [LOG] button at the top of the extension popup
    Copies the latest 500 extension and backend log entries as JSON
    Entries are ordered from newest to oldest
    If the service is offline, local extension diagnostics are copied instead


【FAQ】

  Q: Extension shows "Service not started"
  A: Run "启动服务.bat" (Windows) or "启动服务.command" (macOS)
     Keep the service window open and wait for port 8765

  Q: Higher qualities (4K/1080P60) show lock icon
  A: Log in to Bilibili first, extension reads your login cookie

  Q: Downloaded MKV has no danmaku
  A: Right-click -> Subtitles -> Enable track, or use Hard Burn mode

  Q: The LOG button shows "Copy failed"
  A: This now only means clipboard access failed. Service-offline diagnostics
     are copied automatically. Startup details: backend/logs/startup.log


【Share with Friends】

  Do not include the generated .venv folder when sharing. The recipient should:
  1. Run the startup file for their system (auto-installs dependencies + FFmpeg)
  2. Load the "extension" folder in browser
  3. Open any Bilibili video page
