========================================
  B站视频下载器 - 使用说明
========================================

【前提】
  - Windows 系统
  - Chrome / Edge 浏览器
  - Python 3.10+ (https://www.python.org/downloads/)
    安装时务必勾选 "Add Python to PATH"


【三步安装】

 第1步: 双击 "启动服务.bat"
         - 首次会自动安装依赖，之后直接启动
         - 看到 http://127.0.0.1:8765 即成功
         - 窗口不要关！

 第2步: 加载浏览器扩展
         Chrome: 地址栏输入 chrome://extensions/
         Edge:   地址栏输入 edge://extensions/
         -> 打开右上角"开发者模式"
         -> 点击"加载已解压的扩展程序"
         -> 选择本文件夹里的 "extension" 文件夹
         -> 扩展图标出现在右上角

 第3步: 打开任意 B站视频页面，点右上角扩展图标即可下载


【功能说明】

  下载模式
    [视频+音频]  正常下载 MP4/MKV
    [仅音频]     MP3 / FLAC / Hi-Res 三选一

  弹幕
    [软封装 MKV]  弹幕作为字幕轨道，需 PotPlayer/VLC
    [硬烧录]      弹幕直接刻入画面，任何播放器都能看
                  (下载较慢，文件较大)

  画质
    全部 12 种画质展示，登录后可解锁更高画质


【常见问题】

  Q: 扩展显示"下载服务未启动"
  A: 双击 "启动服务.bat"，看到 8765 端口即成功

  Q: 高画质(4K/1080P60)显示锁图标
  A: 需要登录 B站，扩展会自动读取你的登录态

  Q: 下载的 MKV 没弹幕
  A: 右键 -> 字幕 -> 启用字幕轨道，或用硬烧录模式


【分享给朋友】

  把整个文件夹压缩成 zip 发过去，对方解压后：
  1. 双击 "启动服务.bat" (会自动装依赖)
  2. 浏览器加载 extension 文件夹
  3. 打开 B站视频页就能用

========================================
  Bilibili Video Downloader - User Guide
========================================

【Prerequisites】
  - Windows OS
  - Chrome / Edge browser
  - Python 3.10+ (https://www.python.org/downloads/)
    Check "Add Python to PATH" during installation


【3-Step Setup】

 Step 1: Double-click "启动服务.bat"
         - Dependencies auto-install on first run
         - Keep the window open (service on port 8765)

 Step 2: Load the browser extension
         Chrome: go to chrome://extensions/
         Edge:   go to edge://extensions/
         -> Enable "Developer mode" (top right)
         -> Click "Load unpacked"
         -> Select the "extension" folder in this directory
         -> Extension icon appears in toolbar

 Step 3: Open any Bilibili video page, click the extension icon to download


【Features】

  Download Mode
    [Video+Audio]  Download as MP4/MKV
    [Audio Only]   MP3 / FLAC / Hi-Res (three options)

  Danmaku (Bullet Comments)
    [Soft Mux MKV]  Danmaku as subtitle track (needs PotPlayer/VLC)
    [Hard Burn]     Danmaku burned into video frames (any player)
                    (slower download, larger file size)

  Quality
    All 12 quality tiers displayed, login to unlock higher qualities


【FAQ】

  Q: Extension shows "Service not started"
  A: Double-click "启动服务.bat", wait for port 8765

  Q: Higher qualities (4K/1080P60) show lock icon
  A: Log in to Bilibili first, extension reads your login cookie

  Q: Downloaded MKV has no danmaku
  A: Right-click -> Subtitles -> Enable track, or use Hard Burn mode

  1. Double-click "启动服务.bat" (auto-installs dependencies)
  2. Load the "extension" folder in browser
  3. Open any Bilibili video page
